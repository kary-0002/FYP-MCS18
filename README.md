# Project Description:
This Final Year Project aims to develop an Al-based system to automatically analyze vEEG videos and detect early behavioral patterns related to seizures. The project will apply computer vision and deep learning techniques to recognize facial expressions, emotions, and body movements before and during seizures. Students will work with real, clinician-annotated datasets and build a prototype system that supports early seizure detection and improved clinical decision-making in healthcare. A validated Al-based vEEG analysis prototype that automatically detects and classifies pre-ictal and ictal behavioral patterns in Temporal Lobe Epilepsy using multimodal deep learning, evaluated on clinician-annotated HUKM datasets with predefined performance metrics (e.g., AUROC, F1-score, false positives per hour). The final deliverable will include a working model, evaluation report with quantitative results, and documented system architecture ready for clinical pilot testing.
